1. What is the title of your program?
Disease Spread Simulation System

2. What real-world problem will your program address or help to solve?
This program simulates how an infectious disease spreads through a population over time. It helps analyze how variables such as infection probability and recovery time influence the progression of the disease. This type of simulation can be used to better understand contagion dynamics in a simplified environment.

3. What will you learn from developing this program?
I will learn how to structure a non-trivial Python program using multiple functions with clear responsibilities. I will also improve my ability to model real-world processes using logic and probability. Additionally, I will gain experience writing testable functions and validating them using pytest.
